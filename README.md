# mCMS

mCMS is a self-hosted content management and e-commerce engine built on CodeIgniter 4.

The project is intended to provide a reusable foundation for content-driven websites and online stores without being tied to a specific business or deployment.

## Planned core

- user accounts, roles and permissions;
- pages, news and categories;
- media and galleries;
- site settings and theme support;
- product catalogue, cart and orders;
- stock and delivery configuration;
- administration UI;
- Docker/Portainer deployment;
- clean installation on an empty database through migrations.

## Runtime target

- PHP 8.4;
- CodeIgniter 4.7.x;
- MariaDB 11.4;
- nginx + PHP-FPM;
- Docker Compose / Portainer.
