# Неполадки и безопасность

[К оглавлению](README.md) · [English](../en/troubleshooting.md)

| Симптом | Проверка и решение |
|---|---|
| После распаковки ZIP HTTP 500 | PHP 8.2+, расширения (intl, mysqli, mbstring, gd, zip), `writable/logs`, права записи, реальный `public_html` как DocumentRoot. ZIP исходников GitHub не подходит. |
| HTTP 404 для красивых URL | Apache `mod_rewrite` и AllowOverride, наличие `.htaccess`; в Portainer проверьте внешний reverse proxy. |
| Установщик не соединяется с БД | Хост/порт MySQL, имя БД, права CREATE/ALTER, статус MariaDB. Не пересоздавайте БД действующего сайта. |
| После Re-pull: «pull access denied for mcms» | Обновите `portainer-stack.yml`: `app`, `web`, `updater` должны собираться из Git (`build`), а не `docker pull mcms:dev`. |
| Ничего не изменилось после redeploy | Проверьте ветку `main`, путь Compose, сборку новых образов, их ID, логи `app`. |
| Не открываются изображения | Состояние Media, `modules_data`, PHP/Apache маршрут либо read-only volume для nginx, права на файлы, корректность URL. |
| Не приходит почта | Проверьте SMTP-параметры, TLS, разрешение исходящих подключений у хостинга, SPF/DKIM и почтовые логи. |
| Модуль не устанавливается | Совместимость, зависимости, ZIP-манифест, наличие места/прав; при обновлении отключите модуль заранее. |
| Удаление запрещено | Есть зависимые модули (включая отключённые), встроенный компонент, активная тема, незавершённая операция или отсутствует доказанная принадлежность данных. |
| Долгий HTTP 503 при откате | Не удаляйте флаги вручную. Проверьте архив, остаток диска, MariaDB и логи; при неустранимом сбое восстановите внешнюю копию на совместимую версию. |

## Где смотреть логи

- Docker: `docker compose ps`, `docker compose logs --tail=200 app web db updater`. В Portainer — **Containers → Logs**.
- Shared hosting: раздел PHP error log в панели хостинга и приватный `writable/logs`; журналы Apache — у провайдера.
- Обновления и восстановление: админка `/admin/updates`, `/admin/backups`, `/admin/extensions/recovery`, журналы рабочих операций в приватных каталогах.

## Правила безопасности

Используйте HTTPS; настройте постоянные обновления PHP/ОС и секретные уникальные пароли; не выставляйте порт MariaDB и `writable` в Интернет. Ограничьте доступ к Portainer, обновляйте CMS и сторонние расширения после бэкапа. Авторизованный администратор, устанавливающий ZIP с PHP, фактически разрешает запуск кода; никакой хеш ZIP не превращает сторонний модуль в песочницу.

**Ограничения продукта:** установка поддерживает только одну инстанцию приложения с общими локальными файловыми блокировками. Резервные копии базы и файлов не являются атомарным снимком, если одновременно идёт загрузка медиа. На особо дешёвом shared-хостинге жёсткие лимиты HTTP и отсутствие права менять DocumentRoot несовместимы с безопасной эксплуатацией больших сайтов.
