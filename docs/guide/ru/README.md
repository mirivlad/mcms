# mCMS — руководство администратора (Русский)

**Версия:** серия 0.1.x. Два официальных варианта установки используют одну и ту же CMS, модули и темы:

- **Docker / Portainer** — готовый набор PHP-FPM, Nginx, MariaDB, почты и службы проверки обновлений.
- **Standalone / shared hosting** — PHP 8.2+, корректно настроенный PHP-веб-сервер и MySQL/MariaDB. На хостинге не требуются Docker, SSH, Composer или Node: используется готовый ZIP-релиз.

**Важно:** ZIP архива mCMS содержит данные сайта, а не весь сервер. Для восстановления после потери VPS или аккаунта хостинга нужны также исходный дистрибутив / образы, конфигурация инфраструктуры и копии с другого носителя. Любой ZIP-модуль с PHP-кодом запускается с правами приложения; устанавливайте только проверенные пакеты.
